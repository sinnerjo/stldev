# STL Soccer Dev Lab

**Live site: [stldev.com](https://stldev.com)**

Free soccer coaching apps and guides, built in St. Louis by a youth soccer coach. Every app is a single HTML file that runs in the browser, works offline, and needs no account.

## Apps

| App | What it does |
| --- | --- |
| [SubGo](https://stldev.com/subgo/) | Substitution and playing time tracker for youth games |
| [MatchTap](https://stldev.com/matchtap/) | Live match stat tracking from the sideline |
| [FlappyBall](https://stldev.com/flappyball/) | Soccer themed arcade game with a leaderboard |

## How it's built

Plain HTML, CSS and JavaScript with no build step. Data stays on your device in localStorage. The site is hosted on GitHub Pages and deploys on every push to this repo.
