Help, how to use MatchTap

Modes

Player tracks one kid, no player selection needed, just tap events. Team whole tracks the team as a group with one tap per event, no roster required. Team individual has you tap a player chip first, then the event, giving per player detail at the cost of an extra tap.

Opponent and team name

Type these in Setup so games are labeled clearly. Team name only shows for Team whole and Team individual, since Player mode has no team to name. Both appear in the header while tracking, in Past games, and in shared summaries.

Player and roster details

Number and position are optional for both a single tracked player and each roster entry in Team individual mode. Leave them blank if you don't need that level of detail, they're just there to help tell players apart on the Track screen.

Events to track

Check the boxes for whatever you want live on the Track screen. Everything unchecked stays out of the way, you can turn events on or off any time from Setup.

Score

Track score is on by default and works in every mode, no matter which events you've checked in Setup. Tap either side of the scoreboard on Track to add a goal for you or the opponent. If Goal and Goal conceded also happen to be checked as regular buttons, they add to the exact same score, there's no separate count to keep in sync.

Possession

Available in Team whole and Team individual modes. Turn it on in Setup and two linked buttons appear at the top of Track. Tapping one turns off the other automatically. Time in each state is calculated from the game clock, so it pauses whenever the clock pauses, and totals show up in Log, Past games, and shared summaries as time and percentage.

Game clock

The clock bar on Track is also the start button. Tap it once to begin the game. Tap it again any time to pause, tap again to resume, it remembers exactly where it left off. The Show game clock setting only controls whether the running time is visible, the bar still starts and pauses the game either way. While Track is open, the screen is also kept from locking automatically, so it won't dim mid game just from sitting idle.

Tracking events

In Team individual mode, tap a player chip to select who you're tracking, then tap an event button. Undo last removes the most recent tap if you hit the wrong one. The 1st half and 2nd half buttons just tag new events, they don't affect the clock.

Notes

The Add note button on Track lets you write a short observation tied to the current player and half, useful for anything a tap button can't capture. Notes show up in Log and Past games in quotes, and never count toward event totals or percentages.

Log tab

Shows totals and the full event history for the current game. Percentages appear automatically for stats with both a positive and negative side tracked, like pass completed and pass not completed. Tap the × next to any entry to remove it. Export CSV, Share summary, and Share via QR all send this game's data out in different formats. Save game to history archives everything here into Past games and clears the board so you're ready for the next match. An End game button on Track does the same thing, so you don't have to switch tabs to wrap up.

Combining data from another device

If two people split tracking duties on the same game, Share via QR on Log or on a Past games card displays a code, or a cycling sequence of codes for larger games, that another device can scan. On the receiving side, Import game data on Setup opens the camera to scan it in. If no game is in progress, the scanned data becomes a new game outright. If a game is already in progress, the modes have to match exactly, and anything that overlaps, like both devices tracking the same event for the same player, prompts you to pick which version to keep rather than combining them.

Past games tab

Every saved game lives here. Tap a card to see its full event list, export it to CSV, share a text summary, share it as a QR code for another device to import, or delete it.

Reset current game

Wipes the game in progress, events, score, and clock, without saving anything. Use this for a mis-start, not for ending a real game, that's what Save game to history is for.
